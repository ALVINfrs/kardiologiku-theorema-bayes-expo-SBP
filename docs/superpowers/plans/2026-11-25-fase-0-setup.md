# Fase 0: Setup dan fondasi — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fondasi Expo Kardiologiku yang hijau: repo + scaffold + tema
bertокen + navigasi + utilitas + motion + logo, siap untuk Fase 1.

**Architecture:** Expo Router + TypeScript strict; `src/engine/` dan
`src/sim/` fungsi murni tanpa import React/Expo (bisa dites di Node);
tema satu-satunya sumber hex (`theme.ts`); semua teks UI dari `strings.ts`.

**Tech Stack:** Expo SDK dari `create-expo-app` (PRD §6.3 per Nov 2026 =
SDK 57 — catat versi aktual di DECISIONS.md bila berbeda), `expo-router`,
NativeWind v4.2.x + Tailwind v3, Reanimated 4, Skia, Zustand, Zod,
`expo-sqlite`, vitest, eslint + prettier.

**Spec:** `docs/PRD.md` v1.1 §16 (Fase 0: T-001 s.d. T-006) + `docs/DESIGN.md`
v1.1 (§6 komponen, §15 NativeWind, §16 gerak, §17 logo) + `docs/AGENTS.md`
(§4-§7). Design: `docs/superpowers/specs/2026-11-25-kardiologiku-expo-design.md`.

## Global Constraints

- Satu task = satu commit, pesan `T-xxx: ringkasan`; branch `fase-0-setup`
  dari `main`; jangan `--force`; jangan commit rahasia.
- Tiap task: `npm run typecheck`, `npm run lint`, `npm test` hijau;
  `docs/PROGRESS.md` dicentang (tanggal + 1-2 baris + file);
  keputusan baru di `docs/DECISIONS.md`.
- Tidak ada hex/magic number visual di komponen (pakai token);
  teks UI dari `strings.ts`; komponen interaktif punya `accessibilityLabel`
  dan target ≥ 48dp; 12 kasus emas tetap hijau (mulai T-104, dijaga sejak awal).
- Dilarang: hard-code hex di komponen, kelas warna bawaan Tailwind,
  gradient, blur, `rounded-2xl` (DESIGN §15.4 — `npm run cek:kelas` hijau).
- Dilarang: LLM, Supabase/Firebase, target web, analitik; jangan ubah
  `docs/PRD.md`, seed, skema, atau keputusan terkunci tanpa izin pemilik.
- Domain terms Bahasa Indonesia (`hipotesis`, `bukti`, `riwayat`);
  file `camelCase.ts`, komponen `PascalCase.tsx`; named export
  (kecuali halaman Expo Router).
- Pasang paket SELALU lewat `npx expo install` (versi ikut bundel SDK).
  NativeWind **4.2.x + Tailwind v3**, bukan v5.
- Logo hero (T-006): Blausen 0451 Heart Anterior (CC BY) — verifikasi
  lisensi di halaman berkas pada hari unduh; WebP ≤ 150 KB;
  bila gagal verifikasi/unduh: berhenti di bagian itu, pakai varian
  `mark`, laporkan ke pemilik.
